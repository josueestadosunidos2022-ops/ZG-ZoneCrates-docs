# ZoneCrates

Seven physical reward coffers, matching physical or virtual keys, an administrator editor and the shared GodieCoin wallet.

Siete cofres físicos de premios, llaves físicas o virtuales, editor administrativo y cartera compartida de GodieCoins.

## English — Requirements and quick start

ZoneCore 2.0.0+ is required on the server only. Install the same universal beta4 on server and clients; earlier protocols cannot connect. The portal relation is Optional because it cannot express a server-only requirement for a universal file.

Use `/crates` for the catalog; administrators use `/crates editar`. Select a tier, then Herramientas to give its coffer or keys. Right-click a coffer with a matching physical key, or open its catalog with an empty hand.

### What changed

- Rebuilt symmetrical coffers with centered gems, checked lid joints and phased opening motion.
- Physical openings keep the world visible with a compact reward panel, arcane rings, light beams and phase sounds. Virtual openings retain the roulette.
- Includes beta3 price/state editing, reward details, stale-price and stale-editor checks, full-inventory safeguards and cooldown continuity after death.

## Español — Requisitos e inicio

ZoneCore 2.0.0+ es obligatorio solo en servidor. Instala el mismo universal beta4 en servidor y clientes; los protocolos anteriores no conectan. La relación del portal es Optional porque no permite expresar el requisito solo de servidor en un archivo universal.

Usa `/crates` para el catálogo y `/crates editar` para administrar. Selecciona un nivel y Herramientas para entregar su cofre o llaves. Interactúa con la llave física correcta, o con mano libre para abrir su catálogo.

### Novedades

- Cofres simétricos reconstruidos con gemas centradas, uniones de tapa revisadas y movimiento por fases.
- Las aperturas físicas mantienen visible el mundo con panel compacto, anillos arcanos, haces y sonidos por fase. Las virtuales conservan la ruleta.
- Incluye edición de precio/estado, detalle de premios, comprobaciones de revisiones, protección de inventario lleno y esperas conservadas tras morir.

## Updating / Actualizar

Stop the affected instance, back up world/configuration, replace only the previous same-mod/same-side JAR and retain player data. Never install the dedicated and client JARs of one mod together. / Detén la instancia correspondiente, respalda mundo/configuración y sustituye solo el JAR del mismo mod y lado conservando datos. Nunca instales juntos los JAR dedicado y cliente del mismo mod.
